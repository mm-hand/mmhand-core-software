0. 总主线：这个事件里只有两种数据在流动

方向具体变量说明
上位机发给 P4args.port、port、comm_port、cmd、angles、guarded连接参数和控制命令。最后都会进入 LowerComputerComm.tx_queue，再由 _tx_loop() 写串口。
P4 回到上位机chunk、packets、payload、model: HandModel、current_state、stateP4 原始字节逐步被解析成 HandModel，再通过 callback 给 UI。

7. 用户选择会进入哪些分支：完整决策树

这次事件里，用户不是只“打开 UI”。打开以后每个按钮都会根据当前状态进入不同分支。下面按用户动作拆开。

7.1 用户选择 Port / 自动传入 --port

用户选择/状态进入分支变量怎样传失败出口
启动时传 --port COMx run_ui() 直接调用 backend.connect(port) args.port -> port -> str(port) -> comm_port -> LowerComputerComm.port 连接失败时打印 Connection failed; launching UI without an active device，UI 仍打开。
UI 里选择串口 HandGUI._connect_selected_port() port_combo.currentData() -> port -> backend.connect(port) 无端口：No serial port selected；打开失败：弹 Connection Failed。
换到另一个串口 先 _disconnect_current_port()，再 _connect_selected_port() 旧 current_port 清空；新 port 重走连接链 断开时会清 UI live state 和显示窗口状态。

desktop/core/tendon_guard.py:123
