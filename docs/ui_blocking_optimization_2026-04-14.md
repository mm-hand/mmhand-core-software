# 上位机 UI 与阻塞优化记录（2026-04-14）

更新时间：2026-04-14

改动文件：`ESP32-P4/desktop/ui_main.py`

## 本次目标
1. 优化 Windows 下上位机界面体验（字体、缩放、布局观感、滚轮交互）。
2. 降低上位机启动与运行中的 UI 阻塞。
3. 保持现有控制协议与算法逻辑不变，仅做上位机侧性能与交互优化。

## 已完成改动

### 1. 相机设备探测改为“异步扫描”
- 新增后台扫描流程，不再在 UI 主线程里同步探测摄像头。
- `Device -> Refresh` 与相机面板初始化时，会先显示缓存列表，再异步更新真实可用设备。
- 扫描期间如果重复触发，会合并请求，避免重复阻塞。

对应实现要点：
- 新增 `_request_camera_scan()`、`_on_camera_scan_done()`。
- 相机列表来源从“每次实时阻塞扫描”改为“缓存 + 后台刷新”。

### 2. Windows 相机打开策略优化
- 新增 `_open_cv_capture()`，Windows 优先尝试 `CAP_DSHOW` 打开设备，减少常见的打开延迟。
- 设备探测与实际打开摄像头都走统一打开逻辑。

### 3. 相机刷新降负载（减少无效重绘）
- 相机轮询改为动态间隔：
  - 有相机或有帧时高频刷新。
  - 无相机时低频刷新。
- 增加帧序号判断，只有帧变化时才重绘画布；无帧状态只绘制一次占位，避免重复清空重画。

对应实现要点：
- 新增 `CAMERA_POLL_ACTIVE_MS` / `CAMERA_POLL_IDLE_MS`。
- 新增 `_camera_frame_seq`、`_camera_last_painted_seq`、`_camera_last_blank_drawn`。

### 4. 显示刷新调度去抖（避免 `after(0)` 堆积）
- 将状态更新触发的重绘改为“单一挂起任务 + 固定间隔节流”。
- 高频状态回调不再不断插入 `root.after(0, ...)`，而是合并为一个待执行重绘任务。

对应实现要点：
- 新增 `_request_redraw()`、`_process_pending_redraw()`。
- `_on_state_update()` 改为提交重绘请求而非直接排队立即重绘。

### 5. Windows UI 适配与视觉统一
- 新增 `_apply_platform_ui_defaults()`：
  - Windows 下启用 DPI awareness。
  - 调整 Tk 缩放与默认字体（Segoe UI）。
  - 统一 ttk 主题与基础控件间距。
- 主窗口与启动窗口增加最小尺寸，防止缩放下布局挤压。
- 状态栏增加分隔线与内边距，信息可读性更好。
- 模式按钮与触觉轴按钮使用统一高对比配色（选中态/未选中态更明显）。

### 6. 滚轮交互跨平台一致性
- 新增 `_normalized_mousewheel_steps()` 与 `_bind_canvas_mousewheel()`。
- 处理 Windows / Linux / 小步进滚轮差异，降低 Windows 精细触控板滚动不跟手问题。

## 兼容性与安全性说明

## 2026-04-14 第二轮补充（最大化后控件过小）

### 用户反馈
- 窗口最大化后，滑条及部分控件视觉上仍偏小，放大感不明显。

### 根因
1. 通道表格内部 `Canvas` 的 `create_window` 未绑定宽度同步，内部容器宽度不会随外层增大。
2. 行内 `grid` 未给滑条列分配伸展权重，额外宽度没有分配到滑条。
3. UI 字体/控件内边距未随窗口尺寸变化做分档提升。

### 已修复
1. 为通道表 `Canvas` 增加 `<Configure>` 宽度同步：内部 `inner` 容器宽度跟随可视区变化。
2. 为滑条列添加 `columnconfigure(weight=1, minsize=220)`，让放大后的额外宽度优先给滑条。
3. 滑条默认长度从 `130` 调整为 `220`，在中等窗口下也有更好可读性。
4. 增加根窗口尺寸分档响应（bucket 机制）：窗口变大时提升字体与控件 padding；对 ENABLE/E-STOP 同步增大字体。
5. 右侧手动控制面板重建后会强制重新应用当前缩放档位，避免切模式后尺寸不一致。

### 验证建议
1. 将窗口从默认尺寸拖到最大化，观察 `joint/motor` 两个表中的滑条是否明显变长。
2. 检查按钮、下拉框、状态栏文字是否同步增大且布局不抖动。
3. 切换 `Monitor/Teleoperation/Algorithm` 后再回 `Manual`，确认尺寸策略持续生效。
