# 当前硬件映射说明

本文记录当前固件和上位机使用的主要映射关系。

## 手指与关节顺序

| 手指 | 关节范围 | 磁编/SPI 组 |
| --- | --- | --- |
| 小拇指 | J00-J03 | group0 / SPI5 |
| 无名指 | J04-J07 | group1 / SPI4 |
| 中指 | J08-J11 | group2 / SPI3 |
| 食指 | J12-J15 | group3 / SPI2 |
| 大拇指 | J16-J20 | group4 / SPI1 |

大拇指磁编在机构上的顺序为指尖到指底：

```text
J19, J18, J17, J16, J20
```

## 磁编 SPI 映射

S3 按 `J00..J20` 顺序上传磁编数据，P4 和上位机直接按这个顺序使用，不再二次重排。

| 逻辑组 | 关节范围 | 138 mux 通道 | 151 mux 通道 |
| --- | --- | --- | --- |
| group0 | J00-J03 | 4 | 7 |
| group1 | J04-J07 | 3 | 6 |
| group2 | J08-J11 | 2 | 5 |
| group3 | J12-J15 | 1 | 3 |
| group4 | J16-J20 | 0 | 4 |

来源：`ESP32-S3/System/src/config/Config.h`

## 触觉 SPI 映射

S3 触觉上传顺序为 `G0..G4`，上位机底部标签也按同样的组号显示。

| 触觉组 | 手指 | SPI |
| --- | --- | --- |
| G0(P) | 小拇指 | SPI5 |
| G1(R) | 无名指 | SPI4 |
| G2(M) | 中指 | SPI3 |
| G3(I) | 食指 | SPI2 |
| G4(T) | 大拇指 | SPI1 |

上位机画图时按解剖/视觉顺序摆放：

```text
大拇指, 食指, 中指, 无名指, 小拇指
```

对应的数据来源为：

```text
G4, G3, G2, G1, G0
```

来源：

- `ESP32-S3/System/src/config/Config.h`
- `ESP32-S3/System/src/hal/HalTactile.cpp`
- `desktop/ui/ui_tactile_view.py`

## 舵机 ID 与电机通道

舵机 ID 从 0 开始，并与电机通道号一致：

```text
舵机 id 0 -> M00
舵机 id 1 -> M01
...
舵机 id 26 -> M26
```

当前总线分配：

| 电机范围 | 总线/id |
| --- | --- |
| M00-M07 | bus0 / id0-id7 |
| M08 | bus1 / id8 |
| M09 | bus2 / id9 |
| M10-M14 | bus1 / id10-id14 |
| M15-M19 | bus2 / id15-id19 |
| M20-M26 | bus3 / id20-id26 |

来源：`ESP32-P4/ServoBoardMain/src/hardware/HardwareMap.cpp`

## 注意事项

- 磁编重排在 S3 采集入口完成。
- P4 和上位机不要再次重排 `J00..J20`。
- 触觉重排在 S3 完成，上位机只负责把 `G0..G4` 放到手型图对应位置。
- 改动物理接线或这些映射表后，需要重新标定再进行负反馈控制。
