## 3. 硬件资料

- [ ] 全手 J00～J20、M00～M26 标号照片，与 HardwareMap 对照。

## 5. 接手现场验证

各项填写执行人、时间、版本和结果日志路径；未执行保留“未验证”，不要预先勾选。

| 用例 | 通过标准 | 结果/证据 |
| --- | --- | --- |
| 双击启动 | 无命令行输入打开界面；ROS2 缺失有明确提示 | |
| CLI 兼容 | ui/cli 参数解析、串口选择正常 | |
| 连接 P4 | 状态、关节角、舵机反馈持续刷新 | |
| S3 触觉独立连接 | 摘要和 full 帧可区分，模块新鲜度正确 | |
| 两轮局部标定 | 第二轮完成后第一轮成功关节仍保留 | |
| 标定后锚点保存 | 对应电机 runtime 与 snapshot 锚点有效且读回一致 | |
| P4 原地重启 | 重新同步、恢复完成后原标定关节可用 | |
| P4 重烧录 | 对应设备/模型下恢复结果和多圈状态可解释 | |
| 单舵机掉电 | 同 BUS 其他正常舵机持续反馈，恢复有独立结果 | |
| 标定后 Rope Init | 最终状态与结果一致，失败原因可见 | |
| READY 前反馈请求 | 准入和自动准备符合当前作用范围 | |
| Pause/Resume/E-STOP | 指令、状态、owner 和实际运动一致 | |
| 主机断连/租约超时 | 固件执行预期保持及状态收尾 | |
| 小范围单腱正弦/阶跃 | Target 连续，四曲线可对齐，记录误差和增益 | |
| 双腱控制 | 主副电机方向、LUT 边界和松紧裕量符合实机 | |
| ROS2 授权 | 未点击 ROS2 INPUT 时只接收；授权后才发送目标 | |
| Replay 停止 | 旧目标不继续回放、状态正确收尾 | |
| 保存数据 | CSV 时间、模块编号及触元字段可恢复 | |
| 编译与测试 | 两端构建和相关回归结果有记录 | |
