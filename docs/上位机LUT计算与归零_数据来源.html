runtime · LUT_TIME_FIT / SAMPLE

时间配点的直观关系

示意，不是实机曲线。插值不依赖 host 收包先后。

两种外推要分开

时间轴：禁止。没有共同覆盖、越过无效点、源间隔超限，不能补预测样本。

角空间：仍允许。原 LUT 从有限角覆盖生成完整 URDF 网格；0°附近仍可能来自端点斜率外推。

源时间的物理边界

磁编 time：P4 完整 CAN 快照接收时。

舵机 time：P4 汇总反馈发布时间。

同时间插值消除 host latest 拼点偏差；CAN/S3 采集、舵机轮询延迟、帧间非线性仍需实机验证。它们不是共同硬件触发采集戳。
