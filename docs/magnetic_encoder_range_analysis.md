# 磁编关节行程范围对比

本文汇总 8 组手指磁编码器起止值，并按同类关节比较实际变化范围。

磁编为 14-bit：

```text
1 圈 = 16384 counts
角度 = counts * 360 / 16384
```

## 计算规则

- 普通变化：`abs(end - start)`
- 正向跨圈：`(end - start) mod 16384`
- 反向跨圈：`(start - end) mod 16384`
- 若直接差值明显超过同类关节范围，则结合实际运动方向按跨圈计算
- 手指5、手指6 的 J00 存在机械限位，不纳入 J00 一致性和误差统计

## 数据排查清单

| 优先级 | 数据 | 当前判断 | 建议 |
|---|---|---|---|
| 高 | 手指2 J01：350 -> 12280 | 原记录漏标反向跨圈 | 补充方向标记 |
| 高 | 手指8 J01：10 -> 13260 | 疑似反向跨圈；修正后仍偏小 | 确认运动方向和机械终点 |
| 中 | 手指4 J01：14600 -> 11530 | `3070 counts`，明显偏小 | 复测是否完整打满 |
| 中 | 手指4 J02：1500 -> 14300 | `3584 counts`，低于其它 J02 | 复测是否行程不足 |
| 不排查 | 手指5/6 J00 | 机械限位导致范围偏小 | 不作为误差或异常 |

## 总体结论

- J03 最稳定，适合作为同类手指行程一致性的参考
- J02 整体稳定，主要需要复核手指4
- J01 离散度最大，手指4和手指8明显偏小
- J00 排除手指5/6机械限位数据后，一致性有所改善
- 自动标定或异常检测必须保存方向和跨圈信息，不能只对 raw 起止值做绝对差
