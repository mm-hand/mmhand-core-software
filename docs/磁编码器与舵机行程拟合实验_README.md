#磁编码器与舵机行程拟合实验

## 1. 实验目的

本实验用于检查舵机多圈绝对位置（Servo ABS counts）变化时，关节磁编码器原始值是否近似线性变化，并估算三组机构在本次实测行程内的拟合精度。

本次分析采用最终筛选后的运动数据：

- 删除舵机未运动的重复点。
- 舵机 ABS 与磁编码器数据按时间对齐，允许的最大时间差为 60 ms。
- 对 14 位磁编码器跨越 `0/16383` 的数据进行展开（unwrap）。
- 按舵机每 20 counts 分箱；缺失分箱不插值，不把估算值当成实测值。
- 以筛选后的第一个实测点为锚点进行一次函数拟合。

## 2. 角度换算

磁编码器为 14 位，`16384 counts = 360°`：

```text
磁编码器轴角度 = 磁编码器行程 counts × 360 / 16384
1 count = 0.02197265625°
```

本文中的角度是**磁编码器轴自身的转角**。如果磁编码器与手指关节之间存在传动比、安装偏置或非线性机构，该角度不能直接视为手指关节机械角度。

## 3. 结果汇总

| 关节/舵机 | 舵机统计范围 | 舵机有效行程 | 磁编总行程 | 磁编轴角度 | 线性拟合 | R² | 最大误差 | 最大误差角度 |
|---|---:|---:|---:|---:|---|---:|---:|---:|
| J02 / M03 | M03 ABS ≥ 4500，首点 4520 | 1841 counts | 3860 counts | 84.814° | `J02 = -1.999990 × M03 + 10548.956` | 0.993209 | 207.017 counts | 4.549° |
| J03 / M04 | 7400 ≤ M04 ABS ≤ 9250，首点 7445 | 1802 counts | 4446 counts | 97.690° | `J03 = 2.355885 × M04 - 16687.567` | 0.993541 | 218.493 counts | 4.801° |
| J01 / M02 | 11500 ≤ M02 ABS ≤ 14500，首点 11515 | 2943 counts | 4019 counts | 88.308° | `J01 = -1.124777 × M02 + 28814.808` | 0.947337 | 769.268 counts | 16.903° |

说明：磁编总行程取筛选后配对样本中 `encoder_raw_unwrapped` 的最大值减最小值；最大误差为实测磁编值与拟合理论值之间的最大绝对残差。

## 4. J02 / M03

![J02 与 M03 拟合图](images/磁编码器舵机拟合_20260713/J02_M03_linearity_fit.png)

- 斜率为负，表示 M03 ABS 增加时，J02 磁编码器值总体下降。
- `R² = 0.993209`，在本次有效行程内具有较好的整体线性。
- 最大误差发生在 `M03 ABS = 6307`：实测 `-2272`，理论 `-2064.983`，偏差为 `-207.017 counts`。
- 该组可采用一次函数做粗略映射；如果用于高精度角度控制，仍建议使用分段拟合或 LUT 修正局部偏差。

## 5. J03 / M04

![J03 与 M04 拟合图](images/磁编码器舵机拟合_20260713/J03_M04_linearity_fit.png)

- 斜率为正，表示 M04 ABS 增加时，J03 磁编码器值总体增加。
- `R² = 0.993541`，三组中整体线性最好。
- 最大误差发生在 `M04 ABS = 8132`：实测 `2252`，理论 `2470.493`，偏差为 `-218.493 counts`。
- 该组同样适合先用一次函数描述整体趋势，再用 LUT 补偿局部误差。

## 6. J01 / M02

![J01 与 M02 拟合图](images/磁编码器舵机拟合_20260713/J01_M02_linearity_fit.png)

- 斜率为负，表示 M02 ABS 增加时，J01 磁编码器值总体下降。
- `R² = 0.947337`，明显低于另外两组，末段偏离一次函数的现象较明显。
- 最大误差发生在 `M02 ABS = 14398`：实测 `11851`，理论 `12620.268`，偏差为 `-769.268 counts`。
- 该组不适合只使用单一一次函数进行精确映射。建议优先复测末段机构状态，并采用分段线性拟合或标定 LUT。

## 7. 结论

1. J02/M03、J03/M04 在本次行程内具有较强线性，`R²` 均约为 0.993，可用一次函数表达主要变化趋势。
2. 两组高线性数据仍存在约 `207～218 counts` 的局部最大偏差，因此一次函数更适合作为粗模型，不宜直接替代精密标定表。
3. J01/M02 的最大偏差达到 `769.268 counts`，约等于磁编码器轴 `16.903°`，单一线性模型不足以覆盖整个统计区间。
4. 后续建议对每组机构进行正向、反向各三次重复扫描，分别统计重复性、回差和残差；最终控制映射优先采用按关节保存的分段 LUT。
