## 2. 变量及坐标

以下使用代码中的 logical/raw ABS 有符号计数坐标，不默认数值增加一定收绳。
各电机方向符号翻转不改变内积投影结论；LUT、实际 ABS、斜率必须使用同一坐标和电机顺序。

| 符号 | 中文含义 | 单位 |
| --- | --- | --- |
| i=1,2 | 同一关节 LUT 中两台电机的顺序，不是全手电机编号 | 无 |
| q_r、q_f | 目标关节角、磁编反馈关节角 | 度 |
| x_i | 当前舵机实际 ABS | counts |
| L_i(q) | 第 i 台电机完整标定 LUT 的插值位置 | counts |
| dt | 当前控制间隔；无效或不在 1~100 ms 时退回 10 ms | 秒 |
| k_i | 去掉首尾样本后拟合的有符号斜率 | counts/度 |
| e_i | 等效电机空间角度误差 | counts |
| I_i、v_i | 限幅误差积分、低通误差变化速度 | counts·秒、counts/秒 |
| p_i | 原 PID 的浮点位置修正 | counts |
| z_i、h_i | LUT 配对偏差、扣除调角方向后的恢复偏差 | counts |
| c_i | 限幅后的浮点恢复修正 | counts |
| b_i、u_i | 经过原有边界处理的 PID 命令、最终命令 | counts |

## 3. 去端点斜率和完整 PID

LUT 共 N 点，只使用 j=1 到 N-2；去掉的是两个样本，不是前后各 25% 工作区。

```text
q均 = 内部样本角度的平均值
k_i = Σ[(q_j-q均) × ABS_i,j] / Σ[(q_j-q均)²]
e_i = k_i × (q_r-q_f)
```

分子不减 ABS 均值也成立，因为 Σ(q_j-q均)=0。代码利用内部样本等间隔计算角度。
至少要有两个内部点；不足、斜率非有限或接近零时，回退 e_i=L_i(q_r)-L_i(q_f)，并关闭恢复。
完整 LUT 没有被直线替换；恢复基准仍查询完整 LUT。

```text
I_i = clamp(I_i旧 + e_i×dt, -Imax, +Imax)
v原_i = (e_i-e_i旧)/dt
α = dt/(τ+dt)
v_i = v_i旧 + α×(v原_i-v_i旧)
p_i = Kp×e_i + Ki×I_i + clamp(Kd×v_i, -Dmax, +Dmax)
```

首次控制将误差历史对齐当前值，微分从零开始。Kp 无量纲，Ki 单位 1/秒，Kd 单位秒。
当前 Kp=0.80，Ki=0，Kd=0，Imax=0，Dmax=100 counts，τ=0.050 秒。
所以当前真正生效的 PID 就是 p_i=0.80×k_i×(q_r-q_f)。
这里使用实际 ABS 作为下一次目标基准，不是把 PID 加在 LUT 绝对前馈上；连续周期会继续推进，不能套用固定基准纯 P 的全部直觉。

## 4. 配对恢复

```text
z_i = L_i(q_f)-x_i
a = (k_1×z_1 + k_2×z_2)/(k_1²+k_2²)
h_1 = z_1-k_1×a
h_2 = z_2-k_2×a
```

a 的单位为度，表示偏差中沿拟合调角方向的分量，不是真实角度误差。
满足 k_1×h_1+k_2×h_2=0：恢复不沿这条拟合调角方向推进。
这只是模型近似，不保证实际角度不受弹性、摩擦或非线性耦合影响，更不是张力闭环。

例：k=[20,-20]，L(q_f)=[3000,4000]，x=[2940,3980]。
z=[60,20]，分解为调角分量 [20,-20] 和恢复分量 h=[40,40]。
PID 负责前者对应的角度纠偏；恢复仅处理后者，不强制实际两台完全重合 LUT。

## 5. 死区、限幅和真实最终输出

```text
H = max(|h_1|, |h_2|)
C = min(Cmax, Vmax×dt)
H <= B 时：c_1=c_2=0
否则：s = min(C, G×(H-B))/H
      c_i = s×h_i
```

| 常量 | 当前值 | 中文解释 |
| --- | ---: | --- |
| G | 0.05 | 恢复增益，无量纲 |
| B | 10 counts | 恢复偏差死区，以两侧最大绝对偏差判定 |
| Cmax | 3 counts | 单次每台恢复修正的最大绝对值 |
| Vmax | 200 counts/秒 | 按 dt 换算单次输出上限，不是舵机物理速度保证，也不是输出变化率限制 |
| Enabled | true | 配对恢复开关；关闭不撤销内部斜率 PID |

10 ms 时 C=2 counts。上例 H=40，所以 c=[1.5,1.5]，整数输出各加 2 counts。
没有跨周期累计恢复偏置；小于约 0.5 counts 的项取整为零。取整后不再严格保持投影正交。

代码的严格输出顺序是：

```text
b_i = 会话限幅(LUT裕量限幅(x_i + round(p_i)))
候选_i = b_i + round(c_i)

两侧原 PID 均未触边，且两侧候选都在 LUT/会话范围内：u_i=候选_i
否则整对取消恢复：u_i=b_i
```

不能把它写成 round(p_i+c_i)，因为代码对两项分别取整。
LUT 裕量目前松端 500、紧端 1000 counts，方向由硬件映射决定；这些是允许范围，不是期望预紧量。
反馈角超出 LUT 有效区间时禁用恢复，原 PID 继续按既有安全门禁执行。
碰撞 HOLD 走保持路径，不运行恢复；失效/离线等原有控制准入规则保留。

## 6. 实测调参顺序

1. 先保持当前参数做重复测试和非周期遥操：往返、停顿、随机换向。记录前段和稳定段，不只看最后几秒。
2. 首先确认运行 LUT/固件版本，并补足或离线重建恢复偏差、实际恢复量及触边取消记录，避免把自然机械稳定误认为恢复完全生效。
3. 如果稳定偏差大且恢复量已达上限，单增 G 没用。可单独把 Vmax 从 200 试到 250，再到 300 counts/秒；10 ms 时分别允许 2.5、3 counts，Cmax=3 保持不变。都是待验证试验档位，不是可靠张力参数。
4. 若未饱和但回归慢，再单独将 G 从 0.05 小步试到 0.06；不要同时改 Kp。恢复会双向收/放，观察角度扰动、负载异常和啸叫，异常立即退回。
5. 死区附近抖动先增 B，例如 10 到 15；小偏差无法消除可能来自取整，不应无条件提高恢复速度。
6. 配对漂移稳定后再调角度：Kp 每次小幅改动，分别比较延迟、MAE、峰值和停住误差。当前先保持 Ki=Kd=0；D 是误差微分，非周期目标跳变会产生冲击，不能直接照搬单腱反馈微分参数。
7. 不为贴近 LUT 强行提高预紧。无张力传感时，位置恢复不能证明紧绳安全；外部接触、LUT 迟滞和温漂都可能改变预紧组合。

当前这组日志支持“角度跟随较好、后段漂移明显收敛”，不支持“全程没有放绳、始终具有足够拮抗张力”。
