## 6. 历史资料使用规则

1. 任何历史截图必须标注设备、日期、固件 commit 和是否为当前硬件。
2. 任何历史参数必须重新在当前 `ControlConfig.h`/`CalibrationConfig.h` 核对。
3. 历史日志用于解释回归，不用于证明当前代码行为。
4. 新发现的故障应新增“现象、复现、证据、结论、修复、验证”记录，避免修改
   历史正文后失去时间线。
