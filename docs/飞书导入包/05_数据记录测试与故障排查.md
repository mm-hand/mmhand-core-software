最后核对：2026-09-10

## 2. 测试前检查

1. 记录当前 branch、commit、P4/S3 固件 SHA256 和设备序列号。
2. 保存一份原始 JSON，不在测试中覆盖唯一备份。
3. 确认 active scope、Mxx 路由、Jxx 磁编、Multi-turn 和标定状态。
4. 从单关节、小幅度、低风险速度开始，再扩展到整指/整手。
5. 测试开始和结束都记录状态，不只保存一张图。

## 3. 关节/舵机曲线测试

### 正弦

- 优先读取 `07_遥操作总表.csv` 或 `02_关节总表.csv` 的实际时间轴；
- 同时绘制 target、actual、Mxx CMD/ABS 和磁编角度；
- 统计平均误差、RMSE、相位延迟、峰峰值增益和越界/钳位次数；
- 记录控制 trace sequence gap 和 `p4_time_ms`，防止抽样不均匀造成假结论。

### 阶跃

- 用同样的 P4 elapsed time 和 target token 对齐；
- 区分目标发送延迟、舵机 ABS 响应延迟和磁编角度映射延迟；
- 报告上升/下降时间、稳态误差、超调、进入完成容差时间；
- 不把某一周期的 PID counts 直接等同为机械位移。

可用脚本：`desktop/visualize/plot_sine_response.py`、
`desktop/visualize/plot_step_response.py`、`desktop/visualize/plot_tendon_lut.py`。
运行前先用 `--help`，再确认脚本所需的 CSV 文件名和列名。

## 4. 触觉测试

先验证独立 S3 端口，再判断 P4 CAN relay：

1. S3 串口能打开且端口没有被其他工具占用；
2. 查看 `tactile_data_level`、summary sequence、full sequence、CRC error 和 dropped；
3. 逐个测试五指/三传感器槽位；
4. 持续按压时比较 `module_valid_mask` 与力值，不能用力值为 0 认定离线；
5. 需要触点阵列时启用 FULL 和 `05_触觉全量.csv`；
6. SPI 单路异常时检查 selector pattern、CS/MISO/MOSI/SCLK、CRC 和线缆。

## 5. 典型故障排查

### 上位机连不上 P4

1. 关闭其他串口工具，确认 COM 号没有变化；
2. 确认 `MMHAND_PYTHON` 指向存在的解释器；
3. 使用 `python -m desktop ui --help` 检查环境；
4. 区分“串口打开失败”和“打开后无有效 P4 状态”；
5. 查看 `host_time`、P4 system packet、ACK 和 `Status Age`；
6. 检查 USB-UART 驱动、波特率 921600 和线缆。

### P4 在线但舵机不动

1. 先看 `system_state`、owner、active scope 和 `control_enabled`；
2. 检查 route scan 是否完成、目标电机是否 unique controllable；
3. 检查 Multi-turn Unknown、ABS limit 和标定结果；
4. 区分 `ENABLE`、`START`、`RUN_FEEDBACK` 和 `RUN_DIRECT`；
5. 看协议 ACK、direct reject reason 和安全事件；
6. 不要直接提高 PID，先确认目标是否真正到达 ServoBus。

### 单个舵机离线拖累其他路

查看 P4 `ServoBusTask` 的反馈年龄、离线 bitmap、route state、BUS overload 和
恢复重试。单台离线应隔离到对应 Mxx/BUS；若整条 UART 反复重启，优先排查
驱动层的重试/恢复边界和供电、短路、RX/TX 交叉。

### 标定失败或无法退出

同时查看 `calib_status`、`rope_init_status/reason`、calibration diag 的
Jxx/Mxx、completed/failed bitmap 和安全事件。确认是否为 Manual 缺失、反馈
过期、舵机离线、目标未发布、方向/工作区问题。不要只看一个通用 `FAILED` 文本。

### 重新上电后 Turn Unknown

这是启动保护状态。先等待产品指纹、标定摘要和 multi-turn runtime 恢复；确认
锚点有效且设备身份匹配后才会清除。不要为了绕过 Unknown 在每次开机自动
`RESET ZERO`，因为那会重新定义硬件圈数基准。

## 6. 现场验收矩阵

| 用例 | 通过标准 |
| --- | --- |
| P4 连接 | 状态、舵机反馈和时间戳持续更新 |
| S3 连接 | summary 有效，模块位图和新鲜度正确 |
| 两轮局部标定 | 第二轮不覆盖第一轮成功关节 |
| 标定收尾 | 自动 Rope Init 后进入 READY |
| P4 重启 | 原标定关节恢复，结果可由日志解释 |
| 单舵机掉电 | 同 BUS 其他舵机不被无休止重启拖死 |
| Direct Enable | 不产生位置跳变，保持可信 ABS |
| 正弦/阶跃 | target、actual、CMD、ABS、角度可对齐 |
| 触觉 FULL | sequence/CRC 正确，逐 taxel CSV 可重建 |
| 构建 | P4/S3 编译日志和配置完整保留 |
