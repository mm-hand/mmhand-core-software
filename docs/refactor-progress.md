## 第二批软件改造

- 删除 Manual Workflow、全电机半圈操作和设备 Pause 全链路，退休编号 217 不复用。
- 移除暂停状态准入和暂停恢复缓存；生产 C++ 回归验证退休状态 7 不能授权执行。
- 顶部显示通信、设备状态、当前问题和详情；移除本地 RUN/STOP 指示。
- 装配报警增加对应原因；保留现有阈值与多问题显示。
- 系统状态周期 5 Hz，常规遥测发送节拍上限 100 Hz，保留采集时间戳去重。
- 舵机探测使用独立 3 ms 超时；非阻塞正常读取不再转发无效超时成员。
- P4 eFuse 设备 ID 与协议版本上报；运行锚点按设备 ID 和 URDF 路径隔离。
- 升级备份、未知身份拒绝恢复及设备切换时清理旧锚点缓存。
