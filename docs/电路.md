## 1. 上位机可直接操作的点（运行时）

| 接口/变量 | 你能怎么动 | 直接影响 |
|---|---|---|
| `CMD_START / CMD_STOP / CMD_RESET` | 切换控制使能、复位状态机 | 整机是否输出控制命令、故障状态是否清零 |
| `CMD_ANGLE_CTRL.target_deg[21]` | 改 21 路关节目标角 | 关节闭环目标、动作轨迹 |
| `CMD_MOTOR_POS.motor_raw_single_turn[27]` | 改 27 路直控单圈目标 | 直控模式下电机落点（会做最近圈映射） |
| `CMD_MOTOR_POS_SWEEP.motor_sweep_single_turn[27]` | 连续改滑条值 | 直控扫动平滑性、跨 0/4095 连续性 |
| `CMD_MOTOR_POS_ABS.motor_abs_pos[27]` | 改 27 路 `int32` logical ABS | 经状态准入、Gateway 和最终安全范围裁决后执行 |
| `CMD_MANUAL_ENCODER_REFERENCE / CMD_MANUAL_ENCODER_SINGLE` | 写入 Manual Min/Max 原始值 | P4 Flash 标定基准，影响 Auto 标定和动态角度映射 |

## 4. 你当前最值得动的 8 个点（按优先级）

1. `ControlTask.clampJointTargetDegByCalib` + 双腱 LUT 首末端：验证双腱动态工作空间边界。
2. `EncodersTask.xFrequency` + `CanTask.xFrequency`：先保磁编高频稳定。
3. `TactileTask` 真实采样开关与周期：把触觉从测试链路变成运行链路。
4. 触觉 summary CAN ID 段：先避开 `0x200` 冲突。
5. Manual Min/Max 与 Auto v3 标定快照：保证 P4 映射和上位机状态一致。
6. `SystemTask` 的 PID 参数：做闭环性能调优。
7. `jointMap/motorMap`：硬件连线调整时同步修正映射。

---

## 5. 一句话边界

你能“做手脚”的入口主要是三类：  
1. 上位机命令 payload。  
2. P4 求解与保护阈值。  
3. S3 采样频率与 CAN ID 规划。
