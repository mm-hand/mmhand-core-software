# 电机原生 ABS：简化后的坐标与恢复

本次实现使用用户已经实测确认的硬件能力：开启全角度反馈后，电机直接返回负数和超过一圈的反馈。运行时直接使用这个值，不再根据单圈反馈计算第几圈。

## 日常运行只有一个位置

电机返回原生 ABS → P4 原样保存和上报 → 上位机显示 ABS。

P4 和上位机都不再维护运行圈数。位置包不再传单圈位置，上位机状态和 CSV 也不再保存这套重复字段。Direct Control 不再显示圈数、当前单圈、保存单圈；Motor Calibration 的电机反馈列为 Motor、ABS、Load。

标定算法确实需要圈内相位时，用 `ABS % 4096` 临时计算。这只是数学换算，不是第二套当前位置。

## 什么时候恢复

- 只断开上位机连接，P4 和电机仍在运行且坐标可信：直接使用电机反馈，不重新写坐标。
- 电机掉线后重新上线，P4 还保存着掉线前的可信 ABS：用这一条 RAM 记录恢复。
- P4 重新启动或首次连接，坐标尚未确认：上位机从当前标定包读取已保存的原生 ABS，提交一次恢复请求。
- 明确执行 ABS 归零：建立新坐标，撤销该电机旧的恢复记录和关联自动标定。

没有可用恢复记录时继续显示坐标未知。只有 Motor Calibration 参数并不等于存在可恢复的坐标记录，因此不会因为成功加载参数就直接允许 Feedback Control。

## 一次恢复怎么完成

1. 在停止、无控制所有者且没有急停锁存时执行。
2. P4 上线检查先读取固件主次版本（寄存器0/1），要求至少3.10；低版本禁止控制并由上位机弹窗。版本通过后，确保应答级别为1、角度限位为0、全角度反馈开启、84/85/86为254/254/0。只有不符才关闭扭矩并写EEPROM，最后检查读回和锁状态；每次在线会话只完成一次。
3. 根据保存的 ABS 和当前相位选择最近的一圈。这个计算只发生在恢复开始时。它假定断电期间没有发生超过半圈的未知移动；保存位置无法识别断电期间完整转过的圈数。
4. P4 关闭扭矩，使用 `0x0B` 写入一次完整目标值，并冻结该目标。
5. 等待下一轮正常反馈。只有新反馈的完整 ABS 与冻结目标完全相等，才认定恢复成功。超时为 500 ms；相差整圈、只匹配单圈余数不能通过。
6. P4 上报每台电机成功或失败，成功后解除坐标未知。恢复本身不会自动开启运动。

热插拔、上位机恢复和显式 ABS 归零共用 `ServoAbsoluteRestore.h` 中的一个执行器，串行执行。热插拔允许有限次数继续确认，但已经发出的不确定写入保留原目标，不重算、不重发。STOP 取消正在处理的坐标事务并阻止继续写入。

## ACK 和读回为什么都留下

上位机收到 P4 的 ACK，只说明请求已受理；P4 还要依次与电机通信，所以必须等待最终结果。

电机对 `0x0B` 的 ACK 与完整坐标读回分开处理。收到 ACK 后仍做一次完整值确认；ACK 丢失时也允许下一轮完整反馈证明写入成功。不会因为 ACK 丢失反复写坐标，也不会接受单圈兼容结果。

上位机每次只提交一条恢复请求。8 秒没有结果，只查询一次结果状态，不重发恢复指令；未决请求保留到最终结果或连接会话结束。明确失败后不会持续自动写回，重新导入标定包可以重新开放一次恢复机会。

## 文件与协议

当前标定包是唯一持久化来源，只保存原生 ABS 和有效电机掩码。旧文件中的单圈字段只在导入时校验旧坐标是否一致；不一致的电机不作为恢复来源，标定参数本身保留。新保存不再写该字段。

上位机到 P4 的 `0xDA` 负载为 112 字节：4 字节电机掩码，加 27 个有符号 32 位已保存 ABS，均为大端。它传递恢复记录，P4 负责选择恢复目标。

协议升级为 **6**，需要配套更新上位机和 P4。`0x03` 位置帧只包含 27 个大端有符号 32 位原生 ABS，再加 4 字节 P4 时间戳；完整帧 116 字节。不再包含重复的单圈数组。

本次软件回归和编译不等于新固件已完成实机验收。更新后应重点验证带恢复记录启动、仅上位机重连、电机断电重连、负数与跨圈、整圈不匹配拒绝、恢复中 STOP。

## 上线检查、Direct入口与旧命令清理

上线检查结果由独立的0x20遥测上报：27路，每路为大端uint32在线代次、uint8主版本、uint8次版本、uint8状态，尾部为P4时间；完整帧197字节。状态0等待、1通过、2固件过低、3版本读取失败、4配置失败。结果变化立即尝试上报，缓存每秒重发；状态同步位0x80也可查询。上位机晚连接不需要重新检查电机。失败最多尝试3次、间隔100ms；明确低版本不重试。

Renumber All不再操作84/85/86，维护结果协议为3、负载16字节，不再携带profile。电机重新上线后统一检查配置。

0xEC旧圈数复位已退役，应用不再发送电机0x0A。Release Rope改用0x0B设零，再执行原有相对松绳位移。标定准备阶段一次性建立全部参与电机的坐标：本次重标定电机和无有效标定的邻指让位电机批量设零；已有有效标定的辅助电机保留原坐标，未知时先恢复，恢复失败停止，不能退回归零。逐关节开始不重复设零；边界触发的主动重设零保留。P4控制状态RESET不属于电机坐标设零。

保留Direct无Motor Calibration时的确认弹窗：加载标定或将所有通过上线检查的在线电机设为ABS 0。取消返回原页面；确认会清除相关Auto/LUT、ABS限位及旧恢复记录，保留Manual端点及无关关节。只有完整反馈与新坐标文件保存确认后才允许继续；新设备没有JSON时创建只含恢复坐标的空标定包，不伪造Motor Calibration。
