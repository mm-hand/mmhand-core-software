# Wuji 工作区提交教程

Wuji 工作区已位于主工程的 `wuji_hand_ws/`。`build/`、`install/` 按项目要求保留为可提交文件；`log/` 含机器路径和进程环境，不能提交。包内 `_vendor` 才是 Linux 连接 Wuji 手套所需的 SDK runtime，必须确认它已被 Git 收录。

## Linux 重新构建

现有 colcon 产物记录了旧绝对路径，第一次把代码放到新位置后必须重建：

```bash
cd /path/to/mmhand-cl/wuji_hand_ws
source /opt/ros/jazzy/setup.bash
rm -rf build install log
colcon build --symlink-install
source install/setup.bash
ros2 run wuji_mmhand_teleop wuji_raw_ik_teleop_ui
```

确认 UI 和手套连接正常后，再从主仓库提交新生成的 `build/install`。

## 提交到 cl 分支

```bash
cd /path/to/mmhand-cl
git checkout cl
git status --short

# 确认 Linux SDK、源码以及按要求保留的构建目录均可见
git check-ignore -v wuji_hand_ws/build || true
git check-ignore -v wuji_hand_ws/install || true
git check-ignore -v wuji_hand_ws/src/wuji_mmhand_teleop/wuji_mmhand_teleop/_vendor || true

git add wuji_hand_ws/.gitignore \
        wuji_hand_ws/README.md \
        wuji_hand_ws/tests \
        wuji_hand_ws/src \
        wuji_hand_ws/build \
        wuji_hand_ws/install \
        wuji_hand_ws/提交代码教程.md

git status --short
git diff --cached --check
git diff --cached --stat
git commit -m "feat: integrate Wuji glove ROS2 teleoperation"
git push origin cl
```

## 提交前检查

```bash
git ls-files wuji_hand_ws/src | grep '_vendor/.*\.so'
git ls-files wuji_hand_ws | grep '^wuji_hand_ws/log/' && echo "ERROR: log must not be committed"
ros2 topic info /raw_ik_target -v
ros2 topic hz /raw_ik_target
```

第一条应列出 Wuji SDK 的 Linux `.so`；第二条正常情况下没有输出。
